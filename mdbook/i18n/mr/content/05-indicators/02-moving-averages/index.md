# मूव्हिंग ॲव्हरेज

## प्रस्तावना

अना (काल्पनिक) एका शेअरचा क्लोज भाव पाच दिवस नोंदवून ठेवते. ती ते सगळे आकडे एकत्र करते आणि पाचने भागते. मग ती पुढच्या दिवशीही तेच करते. तिचे आकडे हलतात, पण ते भावाच्या मागे राहतात. वेगळ्या प्रकारची सरासरी अधिक लवकर प्रतिसाद देईल का, असा तिला प्रश्न पडतो. हे प्रकरण दोन सामान्य सरासरी दाखवते: साधी मूव्हिंग ॲव्हरेज आणि एक्स्पोनेन्शियल मूव्हिंग ॲव्हरेज. प्रत्येकाची गणना कशी होते, ते इथे पाहू.

## कल्पना

**मूव्हिंग ॲव्हरेज** म्हणजे ठराविक दिवसांच्या कालावधीतील क्लोज भावांची सरासरी. कालावधी दररोज पुढे सरकतो, म्हणून सरासरीही हलते. तिचे दोन सामान्य प्रकार आहेत.

**साधी मूव्हिंग ॲव्हरेज (SMA).** कालावधीतील प्रत्येक दिवस सारखाच मोजला जातो.

- शेवटच्या N क्लोज भावांची बेरीज करा.
- बेरीज N ने भागा.

चिन्हात: SMA = (शेवटच्या N क्लोजची बेरीज) / N.

N सर्व मूल्ये पुन्हा जोडण्याची गरज न पडता SMA अपडेट करण्यासाठी हा नियम वापरा:

- नवीन SMA = जुना SMA + (आजचा क्लोज वजा N दिवसांपूर्वीचा क्लोज) / N.

कालावधीतून बाहेर पडणारा भाव म्हणजे N दिवसांपूर्वीचा क्लोज. नवीन भाव दुसऱ्या बाजूने आत येतो.

**घातांकी मूव्हिंग ॲव्हरेज (EMA).** अलीकडच्या दिवसांना जुन्या दिवसांपेक्षा जास्त वजन असते. EMA मध्ये **स्मूदिंग फॅक्टर** वापरला जातो, ज्याला k असे लिहितात. तो सर्वात नवीन क्लोजला किती वजन द्यायचे ते ठरवतो.

- k = 2 / (N + 1).
- आजचा EMA = k x आजचा क्लोज + (1 - k) x कालचा EMA.

शब्दांत: EMA कालच्या EMA पासून आजच्या क्लोजकडे k इतक्या भागाने सरकतो. k मोठा असेल, तर प्रतिसाद जलद असतो.

लक्षात ठेवण्यासारखे तीन मुद्दे.

1. **EMA एकाच लांबीच्या SMA पेक्षा जलद प्रतिसाद देतो.** त्याचे अलीकडील वजन जास्त असते.
2. **पहिल्या EMA ला सुरुवातीचे मूल्य लागते.** सामान्यतः पहिला SMA घेतला जातो. ही एक प्रथा आहे, आणि ती सुरुवातीची मूल्ये बदलते. ती नंतरचे तर्कशास्त्र बदलत नाही.
3. **दोन्ही सरासरी मागे राहतात.** N-दिवसांचा SMA स्थिर ट्रेंडच्या सुमारे (N - 1) / 2 दिवस मागे राहतो. हा ढोबळ अंदाज आहे, अचूक नियम नाही.

क्रॉसओव्हर हा मूव्हिंग ॲव्हरेजचा लोकप्रिय उपयोग आहे. जेव्हा लहान सरासरी मोठ्या सरासरीच्या वर किंवा खाली जाते, तेव्हा क्रॉसओव्हर होतो. काही ट्रेडर त्याला ट्रेंडचे चिन्ह मानतात. असे संकेत उपयोगी ठरतात का, हा अजून खुला प्रश्न आहे. पुस्तक हे नियम नंतर Lab 4 मध्ये तपासते.

## हे पाहा

एकाच बनावट भावांवर दोन्ही रेषा पहा. भावाला वळण मिळाल्यानंतर EMA लवकर वाकतो. मग EMA चे सुरुवातीचे मूल्य बदला आणि पहिले काही दिवस कसे बदलतात ते पहा. नंतरची मूल्ये एकमेकांच्या जवळ येतात.

## सोडवलेले उदाहरण

**काल्पनिक.** पाच क्लोज: Rs 100, Rs 102, Rs 104, Rs 103 आणि Rs 105.

**भाग 1. साधी मूव्हिंग ॲव्हरेज.**

| पायरी | गणना | निकाल |
|---|---|---|
| 1. पाच क्लोजची बेरीज | 100 + 102 + 104 + 103 + 105 | Rs 514 |
| 2. 5 ने भागा | 514 / 5 | **Rs 102.80** |

पुढचा क्लोज Rs 107 आहे. बाहेर पडणारा क्लोज Rs 100 आहे.

| पद्धत | गणना | निकाल |
|---|---|---|
| रोलिंग अपडेट | 102.80 + (107 - 100) / 5 = 102.80 + 1.40 | **Rs 104.20** |
| थेट तपासणी | 102 + 104 + 103 + 105 + 107 = 521, मग 521 / 5 | **Rs 104.20** |

दोन्ही पद्धती एकच उत्तर देतात. रोलिंग अपडेट हाताने करायला जलद आहे.

**भाग 2. एक्स्पोनेन्शियल मूव्हिंग ॲव्हरेज, N = 5 सह.**

| पायरी | गणना | निकाल |
|---|---|---|
| 1. स्मूदिंग फॅक्टर | 2 / (5 + 1) | 0.3333 |
| 2. कालचा EMA | सुरुवातीचे मूल्य, पहिल्या SMA इतके ठरवलेले | Rs 102.80 |
| 3. आजचा क्लोज | दिलेला | Rs 110 |
| 4. कालच्या EMA पासून बदल | 110 - 102.80 | Rs 7.20 |
| 5. वजनाचा बदल | 0.3333 x 7.20 | Rs 2.40 |
| 6. आजचा EMA | 102.80 + 2.40 | **Rs 105.20** |

EMA नवीन क्लोजच्या दिशेने Rs 2.40 सरकला. त्याच Rs 110 क्लोजवर SMA Rs 2.00 सरकून Rs 104.80 झाला असता. तपासणी: 102.80 + (110 - 100) / 5 = 104.80. EMA आजच्या क्लोजला जास्त वजन देतो, म्हणून तो जास्त सरकतो.

## हे करून पाहा

### मार्गदर्शित सराव

**काम.** तीन दिवसांचे क्लोज Rs 50, Rs 51 आणि Rs 53 आहेत. पहिला तीन-दिवसांचा SMA काढा. पुढचा क्लोज Rs 56 आहे. नवीन SMA काढण्यासाठी रोलिंग अपडेट वापरा.

संकेत:

1. पहिला SMA = (50 + 51 + 53) / 3.
2. नवीन SMA = जुना SMA + (56 - 50) / 3. बाहेर पडणारा क्लोज Rs 50 आहे.

**उत्तर:** पहिला SMA = Rs 154 / 3 = Rs 51.33, पूर्णांकात गोल केल्यावर. अपडेट केलेला SMA = Rs 51.33 + Rs 2.00 = Rs 53.33, गोल केल्यावर. तपासणी: (51 + 53 + 56) / 3 = 160 / 3 = Rs 53.33.

### स्वतंत्र सराव

**काम.** नऊ-दिवसांच्या कालावधीसाठी EMA काढा, जिथे k = 0.2 आहे. कालचा EMA Rs 500 आहे. आजचा क्लोज Rs 510 आहे. आजचा EMA काढा.

<details><summary>तुमचे उत्तर तपासा</summary>

- कालच्या EMA पासून बदल: 510 - 500 = Rs 10.
- वजनाचा बदल: 0.2 x 10 = Rs 2.
- आजचा EMA: 500 + 2 = **Rs 502.00**.

तपासणी: 2 / (9 + 1) = 0.2, जो k शी जुळतो.

सर्व आकडे काल्पनिक आहेत.

</details>

## मर्यादा आणि नेहमीच्या चुका

- बाजार एकाच पातळीवर फिरत असताना, क्रॉसओव्हर अनेक वेळा दिशा बदलू शकतो. प्रत्येक बदलामुळे खर्चामुळे पैसे जाऊ शकतात आणि स्टॉप-लॉस लागू शकतो. पहा *व्यापारावरील खर्च*.
- क्रॉसओव्हर ही तपासायची नियमावली आहे, नफा मिळवण्याची पद्धत नाही. हे पुस्तक तिला तशी मांडत नाही.
- EMA लवकर प्रतिसाद देतो, पण एका असामान्य दिवसावरही तो जोरदार प्रतिसाद देऊ शकतो.
- EMA चे सुरुवातीचे मूल्य सुरुवातीचे आकडे बदलते. दोन चार्टची तुलना तेव्हाच करा, जेव्हा त्यांचे सुरुवातीचे मूल्य सारखे असेल.
- दोन्ही सरासरी मागे राहतात. त्या ट्रेंड सुरू झाल्यानंतर तो दाखवतात, आणि सुरू होण्यापूर्वी इशारा देत नाहीत.

## लक्षात ठेवा

- SMA = शेवटच्या N क्लोजची बेरीज / N. प्रत्येक दिवस सारखाच मोजला जातो.
- EMA मध्ये k = 2 / (N + 1). आजचा EMA = k x आजचा क्लोज + (1 - k) x कालचा EMA.
- एकाच लांबीच्या SMA पेक्षा EMA जलद प्रतिसाद देतो.
- दोन्ही सरासरी स्थिर ट्रेंडच्या मागे राहतात.
- क्रॉसओव्हर ही तपासायची गृहीतक आहे, खात्रीचा संकेत नाही.
