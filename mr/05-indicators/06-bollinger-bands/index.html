बोलिंजर बँड्स

प्रस्तावना

एक वाचक चार्टवर वरच्या रेषेच्या वर एक क्लोज पाहतो. तो विचार करतो, “भाव खूप वाढला आहे, म्हणजे तो खाली येणार.” तो दुसऱ्या दिवशी सकाळी विक्री करतो. भाव आणखी दोन आठवडे वाढत राहतो. हे प्रकरण सांगते की हे बँड्स काय मोजतात, ते हाताने कसे काढायचे, आणि बँडला स्पर्श झाला म्हणजे तो एकटा संकेत का नाही.

कल्पना

बोलिंजर बँड्स म्हणजे भावाभोवती काढलेल्या तीन रेषा. प्रत्येक रेषेचे काम वेगळे आहे.

  • मधला बँड. शेवटच्या N क्लोजची सरासरी. एक सामान्य निवड N = 20 आहे.
  • स्टँडर्ड डेव्हिएशन (SD). त्याच क्लोजमध्ये ते किती पसरलेले आहेत हे दाखवणारी संख्या. लहान SD म्हणजे क्लोज एकमेकांजवळ आहेत. मोठा SD म्हणजे ते दूरवर पसरले आहेत.
  • वरचा बँड. मधला बँड अधिक k वेळा SD.
  • खालचा बँड. मधला बँड वजा k वेळा SD. एक सामान्य निवड k = 2 आहे.

आधी शब्दांत: वरचा बँड = सरासरी + (k वेळा SD). चिन्हांमध्ये: वरचा = सरासरी + k x SD.

SD काढण्याचे दोन मार्ग आहेत:

  • पॉप्युलेशन SD वर्गफरकांची बेरीज N ने भागते.
  • सॅम्पल SD तीच बेरीज N वजा 1 ने भागते.

टूल्स यापैकी कोणतीही पद्धत वापरू शकतात. John Bollinger यांची स्वतःची साइट सांगते की ते पॉप्युलेशन पद्धत वापरतात. Zerodha च्या चार्टिंग मॅन्युअलमध्ये Kite कोणती पद्धत वापरते हे सांगितलेले नाही, म्हणून दोन टूल्समधील आकडे तुलना करण्यापूर्वी तपासा. (11 Nov 2026 पर्यंत, bollingerbands.com. ही एक सामान्य पद्धत आहे, एक्सचेंजचा नियम नव्हे.)

काही गोष्टी लक्षात ठेवा:

  • बँड्स सरासरीभोवतीचा पसारा मोजतात. ते भाव पुढे काय करेल हे मोजत नाहीत.
  • भाव जास्त हलला की SD वाढतो आणि बँड रुंद होतात. भाव शांत झाला की बँड अरुंद होतात.
  • वरच्या बँडच्या वर क्लोज म्हणजे अलीकडच्या क्लोजच्या तुलनेत भाव कुठे आहे ते दिसते. भाव उलटेल असे ते सांगत नाही.

हे पाहा

आधी मधल्या रेषेकडे पाहा. मग वरची आणि खालची रेषा मधल्यापासून किती दूर आहेत ते पाहा. पॉप्युलेशन वरून सॅम्पल SD वर स्विच करा आणि बँड थोडे कसे हलतात ते पाहा. k 2 वरून 1 करा आणि बँड किती अरुंद होतात ते पाहा.

सोडवलेले उदाहरण

काल्पनिक. पाच क्लोज: Rs 100, Rs 102, Rs 104, Rs 103 आणि Rs 105. आपण N = 5 घेतो, म्हणजे बेरीज हाताने तपासणे सोपे होते. आपण k = 2 आणि पॉप्युलेशन SD घेतो.

पायरीगणनानिकाल
1. मधला बँड (सरासरी)(100 + 102 + 104 + 103 + 105) / 5Rs 102.80
2. सरासरीपासूनचे फरक100 - 102.80, आणि असेच-2.80, -0.80, +1.20, +0.20, +2.20
3. वर्गफरकप्रत्येक फरक स्वतःने गुणा7.84, 0.64, 1.44, 0.04, 4.84
4. वर्गफरकांची बेरीज7.84 + 0.64 + 1.44 + 0.04 + 4.8414.80
5. पॉप्युलेशन व्हेरियन्स14.80 / 52.96
6. पॉप्युलेशन SD2.96 चे वर्गमूळRs 1.72
7. बँडचे अंतर2 x 1.72, न गोल केलेला SD वापरूनRs 3.44
8. वरचा बँड102.80 + 3.44Rs 106.24
9. खालचा बँड102.80 - 3.44Rs 99.36

काम करताना जास्तीचे दशांश ठेवा. शेवटी फक्त गोल करा.

काल्पनिक. तेच क्लोज, सॅम्पल SD. वर्गफरकांची बेरीज अजूनही 14.80 आहे. तिला N वजा 1 = 4 ने भागा. सॅम्पल व्हेरियन्स = 14.80 / 4 = 3.70. सॅम्पल SD = 3.70 चे वर्गमूळ = Rs 1.92 (गोल केलेले). बँडचे अंतर = 2 x 1.9235 = Rs 3.85 (गोल केलेले). वरचा बँड = Rs 106.65. खालचा बँड = Rs 98.95.

सॅम्पल आवृत्ती येथे थोडे रुंद बँड देते. फरक फक्त भाजकामुळे आहे.

हे करून पाहा

मार्गदर्शित सराव

काम. क्लोज Rs 10, Rs 12 आणि Rs 14. N = 3, पॉप्युलेशन SD, k = 2. मधला बँड, SD आणि वरचा व खालचा बँड शोधा.

संकेत:

  1. 10, 12 आणि 14 ची सरासरी म्हणजे मधला बँड.
  2. सरासरीपासूनच्या प्रत्येक फरकाचा वर्ग काढा. वर्गांची बेरीज करा.
  3. बेरीज 3 ने भागा म्हणजे व्हेरियन्स मिळेल. मग वर्गमूळ काढा.

उत्तर:

  • मधला बँड: (10 + 12 + 14) / 3 = Rs 12.
  • फरक: -2, 0, +2. वर्ग: 4, 0, 4. बेरीज: 8.
  • व्हेरियन्स: 8 / 3 = 2.667.
  • SD: 2.667 चे वर्गमूळ = 1.633, जे Rs 1.63 असे गोल होते.
  • बँडचे अंतर: 2 x 1.633 = 3.266.
  • वरचा बँड: 12 + 3.266 = Rs 15.27.
  • खालचा बँड: 12 - 3.266 = Rs 8.73.

स्वतंत्र सराव

काम. क्लोज Rs 200, Rs 204, Rs 196 आणि Rs 200. N = 4, पॉप्युलेशन SD, k = 2. वरचा आणि खालचा बँड शोधा.

तुमचे उत्तर तपासा
  • मधला बँड: (200 + 204 + 196 + 200) / 4 = Rs 200.
  • फरक: 0, +4, -4, 0. वर्ग: 0, 16, 16, 0. बेरीज: 32.
  • पॉप्युलेशन व्हेरियन्स: 32 / 4 = 8.
  • SD: 8 चे वर्गमूळ = 2.828, जे Rs 2.83 असे गोल होते.
  • बँडचे अंतर: 2 x 2.828 = 5.657, जे Rs 5.66 असे गोल होते.
  • वरचा बँड: 200 + 5.66 = Rs 205.66.
  • खालचा बँड: 200 - 5.66 = Rs 194.34.

सर्व भाव काल्पनिक आहेत.

क्विझ

या प्रकरणात बँडचे गणित, दोन SD पद्धतींमधील फरक, आणि बँडला स्पर्श करणे एकटे संकेत का नाही, हे तपासले जाते.

कागदी काम

मोड: कागदी काम (पेपर). हे शिकण्याचे लॉग आहे, व्यापारांची नोंद नाही. ते तुमच्या जर्नलमध्ये लिहा. जर्नल ॲप तयार नसेल तोपर्यंत कागदावर लिहा.

  1. तुम्हाला पाहण्याची परवानगी असलेल्या कोणत्याही चार्टवरून पाच शेअर्स निवडा.
  2. दर आठवड्याला क्लोज लिहा, आणि तो वरच्या किंवा खालच्या बँडच्या बाहेर होता का ते लिहा.
  3. दर आठवड्याला बँडची रुंदी लिहा. बँडची रुंदी = वरचा बँड वजा खालचा बँड.
  4. महिन्याच्या शेवटी लॉग वाचा. काय आश्चर्यकारक वाटले ते लिहा.
  5. लॉगला कोणताही बँड नियम काम करतो याचा पुरावा मानू नका.

मर्यादा आणि नेहमीच्या चुका

  • बँड फक्त मागील क्लोज वापरतात. पुढचा क्लोज कसा असेल याबद्दल ते निश्चित काही सांगत नाहीत.
  • मजबूत ट्रेंडमध्ये भाव एका बँडजवळ बराच काळ राहू शकतो. स्पर्श हा ट्रेंडची सुरुवात असू शकतो, वळण नव्हे.
  • निकाल विंडो आणि SD पद्धतीवर अवलंबून असतो. एकाच क्लोजवरून दोन टूल्स वेगळे बँड काढू शकतात.
  • बँडला स्पर्श करणे एकटे संकेत नाही. नियमासाठी ठरलेली एंट्री, स्टॉप-लॉस आणि चाचणी लागते, आणि मगच कोणी तो वापरावा (बॅकटेस्ट करण्याची मूलतत्त्वे आणि वास्तववादाचा करार यात चाचणी कशी सेट होते ते सांगितले आहे).

लक्षात ठेवा

  • मधला बँड ही सरासरी आहे. वरचा आणि खालचा बँड k वेळा SD मिळवतात आणि जोडतात किंवा वजा करतात.
  • SD पसारा मोजतो. अरुंद बँड म्हणजे क्लोज एकमेकांजवळ होते.
  • पॉप्युलेशन SD N ने भागतो. सॅम्पल SD N वजा 1 ने भागतो. तुमचे टूल कोणते वापरते ते तपासा.
  • बँडच्या बाहेरचा क्लोज ही नोंद आहे. तो अंदाज नाही.
